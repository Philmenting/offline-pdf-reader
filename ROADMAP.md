# Stirling-inspired roadmap (offline-first)

Goal: deliver a local desktop PDF app with practical parity on core personal workflows.

## Near-term
1. Merge/split/reorder pages
2. Rotate/crop pages
3. OCR whole document with progress + language selection
4. Batch rename based on extracted entities
5. Searchable PDF copy after OCR (✅ basic implementation)

## Editor upgrades in progress
1. Visual crop directly in the preview (current page, mouse-driven)
2. Insert image/signature/stamp overlays
3. Proper redaction workflow (irreversible)
4. Edit/fill form fields more directly
5. Better review tools (notes, freehand, replies)

## Mid-term
1. Password protect/decrypt PDFs (local)
2. Image/PDF conversion tools
3. Metadata editor
4. Preset profiles (invoice mode, archive mode)

## Guardrails
- Offline by default and by design
- No cloud API dependency
- Keep attribution/license compliance documented
