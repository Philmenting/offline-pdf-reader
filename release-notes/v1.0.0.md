# Offline PDF Reader v1.0.0 - Ribbon Toolbar Edition

🎉 **Erste stabile Version mit modernisierter Benutzeroberfläche!**

## ✨ Neue Features in dieser Version

### 🔤 OCR & Text-Verarbeitung
- **OCR-Integration**: Lokale Texterkennung mit Tesseract (keine Cloud!)
- **Text-Extraktion**: Automatische oder manuelle Textextraktion aus Seiten
- **Suchfunktion**: Durchsuche alle Seiten mit Trefferliste und Navigation
- **Batch-Rename**: Intelligente automatische Umbenennung von PDF-Dateien basierend auf Dokumentinhalten

### 📄 PDF-Bearbeitung & -Verwaltung
- **Seiten-Navigation**: Erste/Letzte/Gehe zu Seite mit Keyboard-Shortcuts
- **Zoom & Rotation**: Flexibles Zoomen, Links/Rechts Drehen, Drehung zurücksetzen
- **PDF-Zusammenführung**: Mehrere PDFs zu einer Datei kombinieren
- **Seiten-Extraktion**: Bestimmte Seiten in neue PDF exportieren
- **Seiten-Sortierung**: Drag & Drop Umordnung von Seiten
- **Leere Seiten entfernen**: Automatische Erkennung und Löschen leerer Seiten
- **Undo/Redo**: Vollständige Änderungsverlauf-Verwaltung

### 🎨 Benutzeroberfläche
- **Moderne Ribbon-Toolbar**: Office-ähnliches 4-zeiliges Menü-System
  - Reihe 1: Datei, Navigation, Zoom
  - Reihe 2: Rotation, Undo/Redo
  - Reihe 3: OCR & Text, Speichern
  - Reihe 4: PDF-Werkzeuge, Suche
- **Seitenminiatur-Panel**: Visuelle Navigation durch Thumbnails
- **Vorschau-Fenster**: Große, skalierbare Seiten-Anzeige
- **Accessibility**: Volle Unterstützung für Screen Reader

### 💾 Export & Speicherung
- **Mehrformat-Export**: TXT, JSON, CSV für einzelne oder mehrere Dateien
- **Searchable PDF**: OCR-basierte durchsuchbare PDF-Kopien
- **Save-As**: Flexible Speicherung mit vorgeschlagenen Dateinamen
- **Dry-Run Preview**: Vorschau aller geplanten Änderungen vor Ausführung

## 🔧 Technische Details

**Anforderungen:**
- Python 3.11+
- PySide6 (Qt für Python)
- PyMuPDF (PDF-Rendering)
- Tesseract OCR (lokal, keine Cloud-Abhängigkeit)
- Pillow (Bildbearbeitung)

**Betriebssystem-Unterstützung:**
- ✅ Windows 10/11 (mit portierbare .exe)
- ✅ macOS 10.14+
- ✅ Linux (Ubuntu/Debian, etc.)

## 📥 Installation

### Windows (Portable EXE)
1. Lade offline-pdf-reader-windows-portable.zip herunter
2. Entpacke die ZIP-Datei
3. Starte offline-pdf-reader.exe
4. Tesseract ist bereits mitgebündelt!

### macOS / Linux
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

### Tesseract Installation
- **Ubuntu/Debian**: sudo apt install tesseract-ocr
- **macOS**: brew install tesseract
- **Windows**: Bereits im portable Build enthalten
